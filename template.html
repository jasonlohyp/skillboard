What is what?
Skill
A folder of instructions. Claude reads it when the job matches. Like a recipe card.
Agent
A helper Claude starts for one job, with its own memory and its own limits. Like hiring a specialist for an hour.
Plugin
A box that can hold skills, agents and tools together. You install or switch it off as one piece.
Tool
Something Claude can do: read a file, run a command, or use a connected app.
Where it works
"Every project" lives in your user folder. "Only in …" lives inside one project folder.
